Privacy Policy – Logistics Notifier

Last updated: 5 November 2026

1. Google user data accessed

With the user's permission, Logistics Notifier requests a single Google scope: https://www.googleapis.com/auth/spreadsheets.readonly (view Google Sheets). It is used only to read the logistics shipment report spreadsheets that the user has been given access to.

2. How the data is used

Spreadsheet content is read on the user's own computer to prepare draft emails (Arrival Notice and weekly logistics report) in the user's Microsoft Outlook, and a local preview/Excel file. The app does not modify, delete or create any Google spreadsheet or other Google data.

3. Storage

The app has no server. The Google sign-in token and a small log of prepared notices are stored only on the user's computer (in the user's Windows application data folder). Spreadsheet data is not stored anywhere else.

4. Sharing

Google user data is not sold, shared with or transferred to any third party, and is not used for advertising or for training any model. Information leaves the user's computer only in the emails the user decides to send.

5. Revoking access

Users can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the local token by removing the folder %APPDATA%\LogisticsNotifier.

6. Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
